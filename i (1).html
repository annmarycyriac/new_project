One Small Step, Machane!

You're opening the file directly — browsers block AI calls from file://. Serve it over http:// instead.

🐍 Python (easiest — already installed on Mac/Linux)
python3 -m http.server 8080
Run this in the folder where the HTML file lives, then open http://localhost:8080
📦 Node.js (if you have it)
npx serve .
Run in the same folder, then open the localhost URL it gives you
💻 VS Code (click-and-go)
Install the Live Server extension → right-click the HTML file → "Open with Live Server". Done machane, scene aanu!
💡 Why? Browsers block API calls from file:// pages for security. Running a local server takes 5 seconds and fixes it permanently. Offline mode still works right now without any server!
